# TCC — My project (Unity)

Projeto Unity do TCC de Julio Schmidt.

## Requisitos

- Unity (versão registrada em `ProjectSettings/ProjectVersion.txt`)
- Pacotes listados em `Packages/manifest.json`

## Abrir o projeto

1. Abra o Unity Hub
2. Add → selecione esta pasta
3. Abra o projeto e deixe o Unity regenerar a pasta `Library/`
